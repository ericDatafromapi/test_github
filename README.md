# Atelier Git — Projet Démo

Ce petit projet sert à pratiquer les commandes Git de base.

## Objectifs

- Initialiser un dépôt avec `git init`
- Vérifier l'état avec `git status`
- Ajouter des fichiers avec `git add`
- Créer des commits avec `git commit`
- Observer les modifications avec `git diff`
- Créer et fusionner des branches
- Provoquer et résoudre un conflit simple

## Exemple de scénario

1. Modifier `presentation.txt`
2. Ajouter une ligne dans `participants.txt`
3. Modifier le message dans `src/app.py`
4. Créer une branche `feature-salutation`
5. Modifier la même ligne sur deux branches pour provoquer un conflit

Bonne pratique : faire de petits commits avec des messages explicites.
