# Notes de cours

## Commandes essentielles

```bash
git init
git status
git add .
git commit -m "Premier commit"
git log --oneline
git diff
```

## Branches

```bash
git switch -c nouvelle-branche
git switch main
git merge nouvelle-branche
```

## À tester pendant la séance

- Modifier un fichier sans l'ajouter
- Ajouter un fichier au staging
- Faire un commit
- Revenir sur une modification
- Créer une branche
- Fusionner deux branches
